# Project 01 — Nmap Reconnaissance Detection & Triage

This project simulates a network reconnaissance attack and demonstrates how Security Onion detects and alerts on the activity.

## What I Did

Ran three Nmap scans from Kali Linux against a Metasploitable2 target and analyzed the alerts generated by Security Onion.

- SYN scan (-sS): identified 23 open ports
- Version detection (-sV): identified service versions running on each port
- UDP scan (-sU): probed common UDP services

## What Security Onion Detected

52 alert events across 17 distinct Suricata rules. The most notable finding was Suricata fingerprinting the Nmap Scripting Engine from its HTTP user-agent string, identifying the exact tool being used before any exploitation occurred.

## Tools Used

- Nmap
- Security Onion 2.4.211
- Suricata
- Zeek
